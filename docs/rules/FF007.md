# FF007 — Composable Uses Hardcoded Dimensions

## Overview
- **Rule ID**: `FF007`
- **Category**: Compose Rule
- **Default Severity**: `WARNING`
- **Default Confidence**: `HIGH` (>120dp on container) / `MEDIUM` (UNKNOWN role) / `LOW`

## What It Detects
`FF007` identifies hardcoded `.width(...)`, `.height(...)`, or `.size(...)` modifier calls in Jetpack Compose code that lack adaptive cues (`WindowSizeClass`, `BoxWithConstraints`, or conditional layout branches).

## Phase 2 Semantic Policy Rules
1. **Scrollable Ancestors**: A scrollable ancestor (like a parent `LazyColumn`) does NOT automatically suppress FF007 on unscrollable fixed-height child cards.
2. **Internal Scroll Mitigation**: If internal scroll applies directly to the modifier chain (`Modifier.verticalScroll(...)` or `LazyColumn`), FF007 is mitigated.
3. **Fixed Content Cards**: Fixed-size content-bearing cards with dynamic text remain eligible for analysis.
4. **Exemptions**:
   - Small touch targets, icons, badges, spacers ($\le 48\text{dp}$).
   - Small visual elements without text ($\le 64\text{dp}$).
   - Specialized input controls (e.g. OTP cells, PIN inputs, TextFields).
5. **Unknown Component Roles**: Preserved as `UNKNOWN` rather than guessed, evaluated with `Confidence.MEDIUM`.

## Bad Example
```xml
@Composable
fun UserCard() {
    Card(modifier = Modifier.width(350.dp).height(200.dp)) {
        Text("User Profile")
    }
}
```

## Better Alternative
```xml
@Composable
fun UserCard() {
    Card(modifier = Modifier.fillMaxWidth().wrapContentHeight()) {
        Text("User Profile")
    }
}
```

## Known Limitations
- If dimension values are calculated via custom helper functions, static regex matching may not extract the dynamic dp value.
