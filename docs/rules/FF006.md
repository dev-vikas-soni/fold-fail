# FF006 — AbsoluteLayout or Absolute Coordinates

## Overview
- **Rule ID**: `FF006`
- **Category**: XML Layout Rule
- **Default Severity**: `WARNING`
- **Default Confidence**: `HIGH` (`AbsoluteLayout`) / `MEDIUM` (`layout_x`/`layout_y`)

## What It Detects
`FF006` detects:
1. Deprecated `<AbsoluteLayout>` view containers.
2. Views utilizing hardcoded `android:layout_x` or `android:layout_y` placement attributes.

## Why It Matters
Absolute positioning places UI elements at fixed pixel coordinates, breaking completely across different screen densities, aspect ratios, and window sizes.

## Bad Example
```xml
<AbsoluteLayout xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="match_parent">
    <Button
        android:layout_width="100dp"
        android:layout_height="50dp"
        android:layout_x="50dp"
        android:layout_y="120dp" />
</AbsoluteLayout>
```

## Better Alternative
```xml
<ConstraintLayout xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:app="http://schemas.android.com/apk/res-auto"
    android:layout_width="match_parent"
    android:layout_height="match_parent">
    <Button
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        app:layout_constraintStart_toStartOf="parent"
        app:layout_offsetTop_toTopOf="parent"
        android:layout_marginStart="16dp"
        android:layout_marginTop="16dp" />
</ConstraintLayout>
```
