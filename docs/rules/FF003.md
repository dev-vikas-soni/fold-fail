# FF003 — Root Layout Has Fixed Width

## Overview
- **Rule ID**: `FF003`
- **Category**: XML Layout Rule
- **Default Severity**: `WARNING`
- **Default Confidence**: `MEDIUM`

## What It Detects
`FF003` detects XML layout files in `res/layout/` where the root view specifies a hardcoded dp width (e.g., `android:layout_width="360dp"`) without any alternative responsive layout qualifier (such as `-sw600dp`, `-w600dp`, `-land`, etc.) in the project resources.

## Why It Matters
Root layouts with fixed dp widths fail to expand across wider screens, leaving blank gutters on tablets or causing severe content clipping on narrow split-screen panes.

## Bad Example
```xml
<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="400dp"
    android:layout_height="match_parent">
    <!-- Content -->
</LinearLayout>
```

## Better Alternative
```xml
<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="match_parent">
    <!-- Content -->
</LinearLayout>
```
Or provide an alternative qualified layout variant: `res/layout-sw600dp/activity_main.xml`.

## Known Limitations & False Positives
- Fixed-width dialog roots (e.g. 320dp modal dialogs) may trigger `FF003` if placed in standard `res/layout/`.
