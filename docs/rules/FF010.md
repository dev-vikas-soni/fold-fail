# FF010 — Restrictive Modifier Chain Combination

## Overview
- **Rule ID**: `FF010`
- **Category**: Compose Rule
- **Default Severity**: `WARNING`
- **Default Confidence**: `HIGH` (containers) / `MEDIUM` (UNKNOWN role) / `LOW`

## What It Detects
`FF010` detects single composable modifier chains that lock bounds in both horizontal and vertical axes simultaneously (e.g., combining fixed `.width(...)` and `.height(...)`, or specifying fixed `.size(...)`) without internal scroll mitigation or adaptive handling.

## Deduplication Policy
When `FF010` triggers on a modifier chain locked in both axes, `FF007` is suppressed for that chain to prevent redundant duplicate findings on the same line.

## Bad Example
```xml
@Composable
fun ContentCard() {
    Card(modifier = Modifier.width(350.dp).height(500.dp)) {
        Text("Card Content")
    }
}
```

## Better Alternative
```xml
@Composable
fun ContentCard() {
    Card(modifier = Modifier.fillMaxWidth().heightIn(max = 500.dp)) {
        Text("Card Content")
    }
}
```
