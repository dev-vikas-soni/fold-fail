# FF002 — Activity Aspect Ratio is Restricted

## Overview
- **Rule ID**: `FF002`
- **Category**: Manifest Rule
- **Default Severity**: `WARNING`
- **Default Confidence**: `MEDIUM`

## What It Detects
`FF002` detects activity aspect-ratio restrictions configured via `android:maxAspectRatio` or `android:minAspectRatio` when `resizeableActivity` resolves to `false`.

## Resolution Logic
Effective `resizeableActivity` is evaluated in this order:
1. Explicit `<activity android:resizeableActivity="...">`
2. Explicit `<application android:resizeableActivity="...">`
3. Platform default for `targetSdkVersion`: `true` for $\ge 24$ (Android 7.0+), `false` for $< 24$ or omitted.

When effective `resizeableActivity` is `true`, aspect-ratio attributes are ignored by the Android platform, so `FF002` will not fire.

## Why It Matters
Limiting aspect ratio causes letterboxing or pillarboxing on large-screen foldables, tablets, and desktop devices.

## Bad Example
```xml
<activity
    android:name=".DetailActivity"
    android:resizeableActivity="false"
    android:maxAspectRatio="2.1" />
```

## Better Alternative
```xml
<activity
    android:name=".DetailActivity"
    android:resizeableActivity="true" />
```

## Known Limitations & False Positives
- Games requiring fixed 16:9 canvas rendering may intentionally restrict aspect ratio.
