# FF005 — Complex Layout Lacks Adaptive Variants

## Overview
- **Rule ID**: `FF005`
- **Category**: XML Layout Rule
- **Default Severity**: `INFO`
- **Default Confidence**: `LOW`

## What It Detects
`FF005` inspects the DOM complexity of layout XML files. If a layout contains more than 15 total XML view nodes but has only a single default layout configuration (no `-w600dp`, `-sw600dp`, or `-land` variants), `FF005` flags it for review.

## Why It Matters
Complex XML layouts designed exclusively for phone portrait orientations often stretch awkwardly or waste screen real estate on tablets and foldables.

## Bad Example
A 25-node complex form in `res/layout/fragment_checkout.xml` with no corresponding `res/layout-sw600dp/fragment_checkout.xml`.

## Better Alternative
Provide a multi-column qualified layout variant in `res/layout-sw600dp/` or `res/layout-w600dp/`.

## Known Limitations & False Positives
- Layouts using `ConstraintLayout` with percent-based guidelines may adapt fine without needing separate XML resource variants.
