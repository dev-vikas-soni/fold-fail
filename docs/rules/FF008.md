# FF008 — Composable Uses Restrictive Required Size

## Overview
- **Rule ID**: `FF008`
- **Category**: Compose Rule
- **Default Severity**: `WARNING` (containers/large elements) / `INFO` (small elements)
- **Default Confidence**: `HIGH` (containers/large elements) / `LOW` (small elements)

## What It Detects
`FF008` flags uses of `Modifier.requiredWidth(...)`, `Modifier.requiredHeight(...)`, or `Modifier.requiredSize(...)`.

## Why It Matters
Unlike `width` or `height` which respect incoming parent constraints, `required` size modifiers force exact dimensions regardless of parent bounds, guaranteeing content clipping or off-screen overflow when parent constraints are tight.

## Bad Example
```xml
@Composable
fun ContentPanel() {
    Box(modifier = Modifier.requiredWidth(400.dp)) {
        Text("Panel Content")
    }
}
```

## Better Alternative
```xml
@Composable
fun ContentPanel() {
    Box(modifier = Modifier.widthIn(max = 400.dp).fillMaxWidth()) {
        Text("Panel Content")
    }
}
```

## Known Limitations
- Intentionally overflowing canvas graphics or custom badges may require `requiredSize`.
